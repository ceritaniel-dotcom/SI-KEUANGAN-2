# SI-KEUANGAN (Sistem Informasi Keuangan & Anggaran)

Aplikasi web pencatatan pemasukan, pengeluaran, hutang, kontrol batas maksimal bajet bulanan, dan ekspor laporan ke Microsoft Excel (`.xlsx`).

## Fitur Utama
- **Home Dashboard Interaktif:** Ringkasan total pemasukan, rencana vs realisasi pengeluaran, hutang bulan berjalan, pelunasan hutang, saldo akhir otomatis, indikator peringatan bajet, kontrol sisa limit per kategori, serta grafik batang interaktif.
- **Form Input Mobile-Friendly:** Pencatatan cepat pemasukan dan pengeluaran (Langsung Bayar maupun Hutang Dulu).
- **Laporan & Export Excel:** Filter riwayat transaksi berdasarkan tanggal spesifik, bulan, maupun tahun, serta unduh langsung menjadi file `.xlsx`.

## Cara Deploy ke GitHub Pages
1. Buat repositori baru di GitHub dengan nama `si-keuangan`.
2. Upload seluruh isi folder proyek ini (`index.html`, `README.md`, dan folder `assets/`).
3. Buka menu **Settings** > **Pages** pada repositori GitHub Anda.
4. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1-2 menit, lalu buka link GitHub Pages yang muncul melalui browser HP Anda.
